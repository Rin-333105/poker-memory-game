# 花影记忆 · Art Deco 扑克牌配对

一款考验短期记忆与模式识别的网页卡牌游戏。系统持续随机发出不重复的扑克牌，从第 3 张起，判断**当前牌**与**上上张**（往前数第二张）之间：花色相同 / 点数相同 / 全都不同。

## 玩法

- 第 1、2 张仅展示（停留一个作答时限，可点击立即换下一张）
- 从第 3 张起作答，倒计时结束或点击按钮提交
- 答对加分并累加连击，答错/超时扣 1 命
- 生命归零或答完指定题数即结算

| 模式 | 题数 | 时限 | 生命 | 历史牌 | 干扰题 |
|------|------|------|------|--------|--------|
| 简单 | 10 | 20s | 3 | 模糊 | 无 |
| 困难 | 15 | 15s | 2 | 不可见 | 无 |
| 地狱 | 20 | 12s | 1 | 不可见 | 常识题（每 2 题插入） |

键盘 1–4 快速作答。各难度最高分本地保存。

## 本地开发

```bash
npm install
npm run dev          # 开发服务器
npm run build        # 生产构建到 dist/
npm run build:single # 单文件构建到 dist-single/index.html（可双击直接运行）
```

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS + Zustand。
